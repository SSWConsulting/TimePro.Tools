# 0.3.7

Login
- `tp login --tenant <name>` now saves back to `<name>.json` and makes `<name>` the active tenant, even when that file's `tenantId` is different. Before, logging in to an alias such as `northwind-staging` (with `tenantId: northwind`) overwrote `northwind.json` with the alias's credentials and switched the active tenant, without any warning.
