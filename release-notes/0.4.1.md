# 0.4.1

Breaking change
- `tp` now needs .NET 11. Install the [.NET 11 SDK](https://dotnet.microsoft.com/download/dotnet/11.0) before you update. If you have only .NET 10, `dotnet tool update` stops with "Settings file 'DotnetToolSettings.xml' was not found in the package", and the `tp` you have keeps working.

Leave
- `tp leave create` and `tp leave update` take `--less <MINUTES>` to set the break on a leave day. `--less 0` means no break, so a 09:00–13:00 half day counts 4 hours, not 3. `tp leave update --clear-less` goes back to the lunch-break default. The MCP `CreateLeave` and `UpdateLeave` tools take the same values as `lessMinutes` and `clearLess`.
- An update to a part-day leave request that does not give `--start-time` and `--end-time` now keeps the request's own times. Before, it changed them to your full workday.

Daily scrum
- `tp scrum` can no longer stop and wait for ever when `gh` or the macOS rich-text copy writes a lot of error output. Each call now has a time limit, after which `tp scrum` continues without GitHub activity or copies plain text.
