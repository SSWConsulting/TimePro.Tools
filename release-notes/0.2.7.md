# 0.2.7

- Added `tp leave balances import <PATH>` to import Xero leave-balance CSV exports,
  with clear warnings for unmatched employees and safe retry guidance when an
  import result is uncertain.
- Added `tp leave balances status` to show when balances were last imported and
  whether they are stale.
- Added leave-balance status to the default MCP and generated timesheet skill,
  while keeping the destructive import tool in the accounting feature pack.
